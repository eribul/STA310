About this computer exercise.

This exercise follows the lecture Survival analysis and the corresponding parts of Collett, Modelling Survival Data in Medical Research (4th ed.):

  • Chapter 1 — censoring, the survivor function \(S(t)\), the hazard \(h(t)\) and the cumulative hazard \(H(t)\)
  • Chapter 2 — Kaplan–Meier, Nelson–Aalen, median and percentiles, the log-rank test
  • Chapter 3 — Cox proportional hazards regression and hazard ratios
  • Section 4.4 — checking the proportional hazards assumption

Sections 1–6 each contain a short introduction, worked R code that you should run yourself, and questions to answer. The solutions are in a separate document, Computer exercise 1: solutions (vignette("cs1-solutions")), which uses the same numbering as this exercise.

The data are a synthetic Scottish metastatic breast cancer (MBC) cohort, scottish_mbc_cohort, which is distributed with this package. It is not one of the data sets from Collett (2023) — it comes from the teaching material of the Edinburgh Cancer Informatics Group, and the same cohort is used in their online tutorial, which is linked at the end of this document and cited under Data and software.

Learning objectives

After this exercise you should be able to

  • explain right-censoring and the independent (non-informative) censoring assumption;
  • estimate and interpret \(S(t)\) with Kaplan–Meier: survival at fixed times, median survival, and survival curves by group;
  • estimate the cumulative hazard \(H(t)\) with the Nelson–Aalen estimator and relate it to \(S(t)\);
  • test for differences in survival between groups with the log-rank test;
  • fit and interpret a Cox proportional hazards model (hazard ratios with confidence intervals);
  • check the proportional hazards assumption with a log–log plot and cox.zph().

1. Time-to-event data and censoring

In survival analysis the outcome has two parts: how long each subject was followed (the survival time) and what happened at the end of that time (event or censoring). Right-censoring means that we only know that the true event time is larger than the observed time. All the methods in this exercise assume that censoring is independent (non-informative): a patient censored at time \(t\) must be representative of all patients who were still event-free at \(t\).

2. The survivor function and the Kaplan–Meier estimator

The survivor function \(S(t) = P(T \ge t)\) is the probability of surviving until time \(t\) or longer. Without censoring it is estimated by the empirical proportion still event-free. With censoring we use the Kaplan–Meier (product-limit) estimator: at each event time \(t_j\) we multiply by the conditional survival fraction \((n_j - d_j)/n_j\), where \(n_j\) is the number at risk and \(d_j\) the number of events at \(t_j\),

\[\hat S(t) = \prod_{t_j \le t} \left(1 - \frac{d_j}{n_j}\right).\]

The following code fits the overall survivor function and prints the estimate at a few time points:

km_overall <- survfit(Surv(observed_time, status) ~ 1, data = mbc)

3. Hazard and cumulative hazard

The hazard \(h(t)\) is the instantaneous rate of the event at time \(t\) among those still at risk. The cumulative hazard \(H(t) = \int_0^t h(u)\,du\) accumulates the risk over time, and it is linked to the survivor function by \(S(t) = \exp(-H(t))\), i.e. \(H(t) = -\log S(t)\). The Nelson–Aalen estimator estimates \(H(t)\) as the cumulative sum of the event fractions \(\hat H(t) = \sum_{t_j \le t} d_j/n_j\).

The next two code blocks plot the cumulative hazard by hormone-receptor status and compare the Nelson–Aalen estimate with \(-\log \hat S(t)\):

km_hr <- survfit2(Surv(observed_time, status) ~ hormone_receptor, data = mbc)

km_hr |>
  ggsurvfit(type = "cumhaz") +
  labs(x = "Time since diagnosis (months)", y = "Cumulative hazard")

tibble(
  time = km_overall$time,
  nelson_aalen = km_overall$cumhaz,
  neg_log_S = -log(km_overall$surv)
) |>
  filter(time %in% c(12, 24)) |>
  knitr::kable(digits = 3)
time nelson_aalen neg_log_S
12 0.610 0.612
24 1.189 1.194

4. The log-rank test

To compare two or more groups we test the null hypothesis that they have the same survival distribution. At every event time \(t_j\) the log-rank test compares the observed number of deaths in a group, \(o_{1j}\), with the number expected under the null hypothesis if the groups were exchangeable, \(e_{1j} = d_j\, n_{1j}/n_j\), where \(n_{1j}\) is the number at risk in group 1 and \(n_j = n_{1j} + n_{2j}\). The total observed and expected counts are compared with a chi-squared test.

The code below compares the two hormone-receptor groups:

lr_hr <- survdiff(Surv(observed_time, status) ~ hormone_receptor, data = mbc)
lr_hr

#> hormone_receptor=HR-positive 658      527      584      5.57      33.5

5. Cox proportional hazards regression

The Cox proportional hazards model writes the hazard for a patient with covariates \(x_1, \dots, x_p\) as

\[h(t \mid x) = h_0(t)\exp(\beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p),\]

where \(h_0(t)\) is an unspecified baseline hazard. The model is semi-parametric: the baseline hazard is left free, and the covariate effects are summarised by hazard ratios, \(\mathrm{HR} = \exp(\beta)\), which are assumed to be constant over time.

The code below fits a univariable Cox model with hormone_receptor (the reference level is HR-negative):

cox_hr <- coxph(Surv(observed_time, status) ~ hormone_receptor, data = mbc)
tbl_regression(cox_hr, exponentiate = TRUE)

6. Checking the proportional hazards assumption

The Cox model assumes that the hazard ratio between any two patients is constant over time (proportional hazards). Writing \(S(t \mid x)\) for the survivor function, the model implies

\[\log\{-\log S(t \mid x)\} = \log\{-\log S_0(t)\} + \beta x,\]

so the curves of \(\log(-\log \hat S(t))\) against \(t\) for two groups should be parallel if proportional hazards holds. The plot below shows this log–log (log-cumulative-hazard) plot for the two hormone-receptor groups:

survfit2(Surv(observed_time, status) ~ hormone_receptor, data = mbc) |>
  ggsurvfit(type = "cloglog") +
  add_confidence_interval(type = "ribbon", alpha = 0.15) +
  labs(x = "Time since diagnosis (months)", y = "log(-log S(t))")

20. Are the two curves in the log–log plot roughly parallel? What does that say about the proportional hazards assumption for hormone_receptor?

Wrap-up and reporting

When you report a survival analysis, check that you have

  • stated the time origin, time scale and event definition;
  • reported the amount of censoring and any concerns about informative censoring;
  • given number at risk alongside every Kaplan–Meier plot;
  • reported medians and survival at fixed times with confidence intervals, not the mean;
  • paired the log-rank test with an effect estimate (hazard ratio) rather than only a p-value;
  • checked and reported the proportional hazards assumption when using a Cox model;
  • interpreted hazard ratios as relative rates, not as probabilities or relative risks.
