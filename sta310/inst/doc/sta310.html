Overview

sta310 contains two things that are useful when working through the STA310 course in survival analysis at the University of Gothenburg:

  • the 33 data sets that accompany Collett (2023), Modelling Survival Data in Medical Research (4th edition), documented with the background of each study and the coded variables; and
  • a small set of teaching functions that implement the estimators from the lectures from first principles, so that every step in the calculation can be inspected rather than hidden inside a black box.

The teaching functions are not meant to replace the established implementations in survival and related packages. On the contrary, most of them agree with survival to within numerical tolerance, and the exercises compare the two.

The Kaplan-Meier estimator

Cox regression fitted from first principles

cox_fit() maximises the partial likelihood with Newton-Raphson and handles tied event times with the Breslow or Efron approximation. Factors have to be expanded before the call, and the intercept column must be dropped, because a Cox model has no intercept:

fit <- cox_fit(myeloma$time, myeloma$status, myeloma[, c("age", "bun")])
fit
#> Cox proportional hazards model (Newton-Raphson, efron ties)
#> n = 48, events = 36, iterations = 7
#> partial log-likelihood = -102.7
#> 
#>  term   estimate std_error         z   p_value
#>   age -0.0001542  0.026230 -0.005879 0.9953000
#>   bun  0.0201500  0.005732  3.516000 0.0004386
x <- stats::model.matrix(~ factor(group), data = bmt_leukaemia)[, -1, drop = FALSE]
cox_fit(bmt_leukaemia$time, bmt_leukaemia$status, x)
#> Cox proportional hazards model (Newton-Raphson, efron ties)
#> n = 23, events = 12, iterations = 6
#> partial log-likelihood = -29.73
#> 
#>            term estimate std_error       z p_value
#>  factor(group)2  -2.1840    1.1340 -1.9260 0.05409
#>  factor(group)3   0.3675    0.6184  0.5942 0.55240

The coefficients, standard errors and log-likelihood agree with survival::coxph():

ref <- survival::coxph(survival::Surv(time, status) ~ age + bun, data = myeloma)
cbind(cox_fit = coef(fit), coxph = coef(ref))
#>           cox_fit         coxph
#> age -0.0001542319 -0.0001542319
#> bun  0.0201535963  0.0201535963

Empirical hazards

emp_hazard() estimates the hazard by a piecewise constant function: events divided by the person-time at risk in each interval. Censored observations contribute person-time but no event. This is the estimator used in the lectures to show how a frailty model produces a decreasing population hazard even when every individual has a constant hazard.

emp_hazard(iud$time, breaks = seq(0, 130, by = 26), status = iud$status)
#>         bin lower upper midpoint n_events person_time      hazard
#> 1    [0,26]     0    26       13        2         421 0.004750594

Sample size and power for the log-rank test

n_events_logrank() gives the number of events required by Schoenfeld’s formula, and power_logrank() is the inverse calculation. Collett’s worked example compares a five-year survival of 0.41 with 0.60:

hr <- log(0.60) / log(0.41)
hr
#> [1] 0.5729326
n_events_logrank(hr)
#> [1] 135.4771
ceiling(n_events_logrank(hr))
#> [1] 136
power_logrank(d = 140, hr = 0.57)
#> [1] 0.913964

power_logrank_sim() simulates trials with exponential survival times and estimates the power by simulation instead, which is useful when proportional hazards, no loss to follow-up or a fixed number of events cannot be assumed:

power_logrank_sim(
  n = 400,
  hr = 0.57,
  lambda0 = -log(0.41) / 60,
  accrual = 18,
  followup = 24,
  nsim = 200,
  seed = 1
)
#> [1] 0.905
#> attr(,"nsim")
#> [1] 200

Competing risks

cif_cause_specific() builds the cumulative incidence function for each cause from cause-specific Cox models, with the other causes treated as censored:

cause_specific <- list(
  thrombosis = survival::coxph(survival::Surv(time, cof == 2) ~ age, data = liver),
  other = survival::coxph(survival::Surv(time, cof == 4) ~ age, data = liver)
)
cif <- cif_cause_specific(
  cause_specific,
  newdata = data.frame(age = 60),
  times = c(365, 1825)
)
round(cif, 3)
#>      thrombosis other
#> [1,]      0.028 0.040
#> [2,]      0.035 0.071
#> attr(,"survival")
#> [1] 0.9343107 0.8974288

The overall event-free survival that the integral is built on is attached to the result:

attr(cif, "survival")
#> [1] 0.9343107 0.8974288
